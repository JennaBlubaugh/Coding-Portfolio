Coding Assignments from Class

  • 2025-2026 Web Design Capstone Project [in progress]: Goblin Gizmos

    • Coming Soon

    The Capstone Project required students to be paired with randomized teammates and to create an application or website either creating a new idea or building upon an existing concept. I acted as the project leader and engineering lead for our project, called Goblin Gizmos. Goblin Gizmos is a website for collectors to show off their collections and interact with others, providing a space for beginners and experts alike.

    This website utilizes HTML, CSS, JavaScript, PHP, and MySQL databases. Will be implemented into Supabase and transported in a Docker container

    • This assignment is a CMS platform that allows users to uplaod reviews of movie, make comments on other movie reviews, see a list of their own personal reviews, and admins can manage posts. Video only, as this was uploaded to the UCF student server.
